# AEON MATRIX KPI Engine

## Objective

Calculate enterprise KPIs from operational events.

## Core KPIs

- OTIF (On Time In Full)
- SLA Compliance
- Inventory Accuracy
- Inventory Turnover
- Warehouse Productivity
- Fleet Utilization
- ETA Accuracy
- Order Cycle Time
- Fill Rate
- Value Recovery
- Waste Reduction
- Forecast Accuracy

## Data Sources

- WMS
- TMS
- ERP
- Telemetry Hub
- Executive Dashboard

## Output

- KPI Summary
- Alerts
- Executive Dashboard
- AI Decision Engine
